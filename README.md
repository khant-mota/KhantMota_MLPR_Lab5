# MLPR Lab 5 – Face Detection & Clustering using HSV and K-Means

## Overview

The goal is to:
1. Detect faces of Plaksha Faculties.
2. Plot the Hue and Saturation of the faces.
3. Perform K-Means Clustering on the facial colour features.
4. Classify the Template Image of Dr. Shashi Tharoor based on learned Clusters.
